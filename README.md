# Roadmap Courses

Схема, экосистема и локальное управление образовательным портфелем по практической кибербезопасности.

## Запуск

```powershell
.\run-dev.ps1 -p 3100
```

- `/` и `/view/edtechlab-main-map` — простая схема форматов, названий и годов.
- `/ecosystem/edtechlab-main-map` — интенсивы, профессиональные программы и BASE по направлениям; мостики и модель предложения.
- `/editor` — программы, годы, направления кибербезопасности и связи.

Изменения сохраняются сразу. Публикация не требуется. При ошибке сети форма сохраняет текст, при конфликте вкладок новые данные не перезаписываются.

В экосистеме сплошные линии — подтверждённые связи, пунктир — предложения, требующие подтверждения состава. Фильтры позволяют выбрать направление и год, показать связи одной программы или всех. Для пары «модуль — интенсив» названия синхронизируются, годы задаются отдельно.

Светлая и тёмная темы запоминают выбор; локальный шрифт Onest включён в сборку.

## GitHub Pages

Публичная версия собирается как статический снимок. «Схема» и «Экосистема» сохраняют фильтры, карточки и интерактивные связи. «Управление» публикуется в режиме просмотра, потому что GitHub Pages не предоставляет сервер для записи в `data/store.json`.

Перед публикацией актуализируйте снимок и проверьте сборку:

```powershell
npm run sync:pages-data
$env:GITHUB_PAGES='true'
$env:PAGES_BASE_PATH='/roadmap-courses'
npm run build:pages
```

Workflow `.github/workflows/deploy-pages.yml` публикует каталог `out` после каждого push в `main`.

## Данные и доступ

Состояние находится в `data/store.json`. Однократные миграции дополняют актуальное сохранение и создают резервные копии. Годы и названия, внесённые пользователем, сохраняются; удалённые пользователем программы не восстанавливаются. Исторические версии и прежние компоненты графа сохранены для совместимости, но не используются текущими страницами.

Пароль управления можно задать через `EDITOR_ACCESS_KEY` в `.env.local`. Без неё локальная панель открывается свободно.

Для изолированной проверки доступны `CATALOG_DATA_DIR` (отдельное хранилище) и `NEXT_DIST_DIR` (отдельная сборка). Не используйте одну папку сборки одновременно для нескольких серверов.

## Проверка и описание модели

`npm run typecheck` — проверка типов. `npm run build` — сборка.

Текущая структура, годы BASE, подтверждённые и предлагаемые связи, модель доступа и сценарии QA описаны в `docs/ecosystem.md`. Отчёт и снимки находятся в `output/playwright/`. Старые тесты React Flow относятся к прежнему редактору и не описывают текущий интерфейс.
